# 交付说明

## 普通 Skill 安装入口

能力版本为0.1.22，人物版本为1.1.6。随包简历的手机号和邮箱已脱敏；六份人物知识与面试回答规则保持不变。完整 `skills/interviewtwin/` 已携带审核人物的只读初始化材料；通用安装器只复制该目录即可。安装收尾或首次使用由Skill调用bootstrap离线初始化到工作区people，无须用户再执行产品安装命令。更新沿用原安装器，然后显式同步绑定人物；只升级能力时保留人物版本。草稿、自建人物、原件与旧快照在Skill外保留。

通用更新的能力替换和人物同步是两个阶段，失败分别报告，不宣称跨工具原子性。旧专用安装器仍可用。当前有效入口以 [INSTALL.md](../INSTALL.md) 为准；下文说明保留的终端安装与更新方式。


## 安装与更新（2026-10-25）

当前交付为能力0.1.22、人物1.1.6及安装器0.2.0，统一从正式GitHub仓库获取。

完整 Git 副本经来源、commit与干净状态核验后直接安装，不再次下载 ZIP。只有安装器时优先 Git 获取一次；ZIP 为明确备用路径，优先系统 curl。更新先检查原来源 commit；未变且安装内容完整时跳过完整下载，有变化才获取一次。资料保护、固定ref与会话加载边界保持不变。

安装器脚本独立保留当前经审核版本与哈希，不直接执行下载包内工具。旧入口迁移需读取最新 INSTALL 并审核工具；新入口日常更新使用保留工具。具体命令、失败分类与停止条件以 [INSTALL.md](../INSTALL.md) 为准。

本轮文件机制验证与真实 Agent 聊天验证分别报告，见 [交付验证结论](交付评测结论.md)。不得把目录适配测试称为 Cursor/其他宿主聊天安装已通过。

本版本包含能力0.1.22、赵家奇人物1.1.6（随包知识及已审核简历）、安装更新工具、产品说明、评测集与方法、简明结果和真实样例。正式仓库：https://github.com/vanci444-hue/InterviewTwin。
