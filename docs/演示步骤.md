# 演示步骤

1. 按[使用说明](使用说明.md)安装，在新会话介绍餐小美与本人职责。
2. 追问一个产品取舍和一个指标口径，要求查看依据。
3. 提供自己的简历创建草稿，试问并纠正一处内容，分别确认内容与可提供范围，生成个人版本。
4. 切回赵家奇，检查人物经历没有混用。
5. 按原来源最新INSTALL.md更新，再开新会话核验版本与资料。

没有新版时应报告版本未变。正式GitHub入口见README；已有结果与必要限制见[评测结论](交付评测结论.md)。
