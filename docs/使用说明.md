# 使用说明

## 安装与开始面试

在独立工作区对Agent说：

> 请按〔交付包解压目录〕中的 INSTALL.md 安装 InterviewTwin 到当前工作区，让我面试赵家奇。

具体环境和命令见[INSTALL.md](../INSTALL.md)。安装后打开目标工作区、新建会话并提问：

> 面试赵家奇。介绍餐小美及你的职责。
>
> 为什么先做单日规划？800万元是如何估算的？这部分是历史上线还是补充设计？

可要求缩短、展开或查看依据。面试纠错只影响对话；持久修改需进入资料维护流程。

## 创建自己的版本

> 我要创建自己的分身。这是我的简历，请整理成草稿，让我试问。

提供资料→试问纠错→确认内容→确认可提供范围→生成独立人物版本。无需手写Skill指令。一份简历可先形成最小知识，新增项目和长期风格后按需拆分。原件按人物保存，审核选择后随包提供。

文字、Markdown/TXT可直接整理；PDF、图片等格式的理解取决于宿主读取能力。读取失败时提供可读文字。创建与导出不自动公开发布。

## 维护与更新

修改个人资料时说“请先展示修改差异，确认后保存”。更新分发版本时说：

> 请按原安装来源的最新 INSTALL.md 更新 InterviewTwin，保留我自己创建的人物、原件和草稿，并验证实际加载版本。

默认同步能力和绑定人物；明确“只升级能力”才排除人物更新。正式内容有本地修改时暂停覆盖；自建人物、草稿与旧快照保留。本地安装来源目录需保留，固定版本来源不自动跟随新版。更新后新建会话核验。

## 评测

文件完整性检查与回答质量分开。执行方法见[评测运行说明](评测运行说明.md)，已有结果见[评测结论](交付评测结论.md)。相似度需本人判断，自动评审不代替确认。

Codex是已实测环境；其他宿主和附件解析限制见[交付说明](交付说明.md)。
