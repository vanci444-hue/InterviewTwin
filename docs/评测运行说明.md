# 评测运行说明

先将Skill和人物安装在独立工作区，评测材料留在交付目录。需要已登录且能调用模型的Codex CLI、Python 3.10+，评测依赖见requirements-eval.txt。运行会消耗宿主模型额度。

```bash
python3 -m pip install -r requirements-eval.txt
python3 scripts/run_suite.py --home /独立面试工作区 --person zhaojiaqi --cases tests/evaluation/core-015.json --output /新结果目录 --jobs 2
```

其他人物：把person换成其稳定标识，并使用该人物专属cases。题库metadata填写persona姓名和person_id；每条interview用例提供id、questions、expected、forbidden、sources。先根据该人物确认资料形成检查点，由创建者核对；不能把赵家奇的数字复制为他人标准答案。second-person-015.json是林舟合成用例的格式示例，人物资料不随默认人物交付，不能不创建林舟就直接运行。

执行顺序：核对人物身份与当前快照→每组新会话、组内连续追问→保存原始回答和工具事件→独立无工具模型评审→Markdown解析检查。只把问题交给分身，expected和forbidden不会进入被测提示。评审读取实际受检版本，而不是默认作者资料或所有历史快照。身份、版本或内容哈希不匹配即停止。

查看answers中的真实记录、judgments中的逐项结论与quality_score、rendering.json中的未解析标记。脚本退出成功只表示执行完成：verdict=fail、低于9分、证据有歧义、来源未核实和待本人确认分别列出，不取平均掩盖事实错误。运行环境与脚本指纹可追溯，模型未显式指定时不猜测型号。

本人确认回答像不像自己、观点能否代表自己；现实非开发者测试能否独立上传、理解审核并纠错。操作测试必须实际安装和更新，不能让语言模型凭文字回答判定操作通过。

历史0.1.15的core-015的K01/K03/B02/B03/B08为可见回归，N01是运行前新冻结的追问，未用其结果优化指令，但不宣称严格盲测。历史全量成绩不能替代当前核心回归结果。原始输出保留，不为排版或分数改写。

当前0.1.18仅进行打包与安装核验，未按此方法重新运行问答；历史结果不作为新版全量通过证明。
